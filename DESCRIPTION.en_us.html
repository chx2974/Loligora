Loligora is a variable sans-serif typeface for screens and documents. It sits between a classic neo-grotesque and a superellipse sans: the round letters are softly squared, with visible flat sides, while everything else stays calm, even and rational.

The weight axis runs continuously from a hairline Thin (100) to a very heavy Black end (up to 950), with upright and italic styles. The italic is a corrected oblique of 9 degrees with a single-storey a.

Every digit has exactly the same width at every weight, in both styles, like the default font in a spreadsheet, so columns of figures align without extra settings. Proportional figures are available through the pnum feature.

Loligora supports Western and Central European Latin languages, with kerning, mark positioning and capital-height accent forms. The glyphs are generated from Python code and a shared set of parameters, so the weights stay consistent with each other.
