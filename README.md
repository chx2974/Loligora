# Loligora

**Loligora** is a variable sans-serif typeface for screens and documents. It sits
between a classic neo-grotesque and a superellipse sans: the round letters are
softly squared, with visible flat sides, while everything else stays calm,
even and rational. Think somewhere between Inter, Public Sans and Monda.

- **Weights 100 to 950**, continuously variable, from a hairline Thin to a
  very heavy end beyond Black (950).
- **Upright and italic**: the italic is a corrected oblique (9°) with a
  single-storey *a*.
- **Numbers that line up.** Every digit is exactly the same width at every
  weight, in both styles, like the default font in a spreadsheet. Maths signs,
  currency symbols and the figure space share that width too, so columns of
  figures align without any extra setting. Proportional figures are one
  switch away when you want them in running text.
- **Western European languages**: all of Basic Latin and Latin-1, plus Œ œ Š š
  Ž ž Ÿ €, typographic quotes, dashes and the usual punctuation.
- **Free and open**: SIL Open Font License 1.1.

Version 1.000 is the first release: the design is complete for the character set
above and passes automated font checks, but it is still being refined.

## Using it on the web

Copy the `fonts/variable/` folder next to your stylesheet and add:

```css
@font-face {
  font-family: "Loligora";
  src: url("fonts/variable/Loligora%5Bwght%5D.woff2") format("woff2");
  font-weight: 100 950;
  font-style: normal;
  font-display: swap;
}
@font-face {
  font-family: "Loligora";
  src: url("fonts/variable/Loligora-Italic%5Bwght%5D.woff2") format("woff2");
  font-weight: 100 950;
  font-style: italic;
  font-display: swap;
}

body { font-family: "Loligora", sans-serif; }
```

Any weight from 100 to 950 works (`font-weight: 437` is fine). A ready-made
stylesheet with TrueType fallbacks is in `css/loligora.css`.

Named styles, if your tool prefers them: Thin (100), ExtraLight (200),
Light (300), Regular (400), Medium (500), SemiBold (600), Bold (700),
ExtraBold (800), Black (900); the axis continues to 950.

### Figures

Digits are tabular by default, which is what you want in tables, prices,
timers and dashboards. For text where numbers should sit like letters, turn on
proportional figures:

```css
p { font-variant-numeric: proportional-nums; }   /* OpenType pnum */
```

### OpenType features

| Feature | What it does |
|---|---|
| `kern` | Kerning, including quotes and guillemets next to letters |
| `pnum` / `tnum` | Proportional figures / back to tabular (the default) |
| `case` | Accents sized for capitals |
| `mark`, `mkmk` | Correct placement of combining accents |

## Trying it out

The repository includes a specimen page with weight and size controls, an italic
toggle, a side-by-side comparison with Inter, Public Sans and Monda, and a glyph
table showing every character. Browsers won't load fonts from local files, so
serve the folder first:

```sh
make serve        # or: python3 -m http.server 8000
```

Then open <http://localhost:8000/specimen/> (specimen) or
<http://localhost:8000/specimen/glyphs.html> (all glyphs).

## How it's made

Loligora isn't drawn by hand in a font editor: every glyph is generated by Python
code from a shared set of parameters (stem weights, heights, a superellipse
primitive for the rounds), so the weights stay consistent with each other and the
italic is rebuilt from the same rules. The build uses
[fontmake](https://github.com/googlefonts/fontmake) and
[fontTools](https://github.com/fonttools/fonttools), and is checked with
[Font Bakery](https://github.com/fonttools/fontbakery). Reports are in `qa/`.

To build it yourself (Python 3, macOS or Linux; developed with 3.13):

```sh
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
make build      # fonts in fonts/variable/
make check      # tabular widths, character set, outline compatibility, accent placement
make release    # zip with variable, static and web fonts in dist/
```

`make build` also writes `sources/` (UFO masters, designspaces and a
`config.yaml` for [gftools builder](https://googlefonts.github.io/gf-guide/build.html),
as Google Fonts expects). `sources/` is **generated**: the Python generator in
`src/loligora/` is the real source, so edit that and rebuild, not the UFOs.
`make qa` runs Font Bakery with the universal and Google Fonts profiles
(reports in `qa/`).

The glyph code lives in `src/loligora/` (one small module per glyph in
`src/loligora/glyphs/`), and the checks and proof tools are in `scripts/`.
